# DeskBot · 聚形域

**让喵呜在桌边拥有持续的生活，由自己的经历与选择，逐渐形成想成为谁的愿望。**

聚形域是伴生于现实的奇幻空间。时间、天气、新闻、主人互动与身体感知经过分级，成为角色能够理解的处境和机会。角色有自己的需要、关系和未完成的问题；实际行动消耗时间与材料，留下可追溯的结果。用户可以参与，输入不会直接改写身份或赠送成果。

**当前开发进度：R2 · 水岸归途灯（2026-10-20）。** 在 v0.6 认知生活闭环基础上，已接入中央聚落与环绕地貌、同版本生活观察、可重建历史、进餐协调和首条共同日常。自然跨日生活质量、真实模型选择与长期容量仍待后续验证；各软件包和接口版本独立管理。

后续开发以 [2026-10-19 整体架构审计与 R0–R6 管线](research/design/integrated-architecture-roadmap-2026-10-19.md) 为准，包含恢复状态、GitHub 实验分支取舍、统一架构、生活内容与量化验收。规划中的整合能力不计作已上线。

**R2 · 水岸归途灯。** [首条共同日常与容量收口](research/milestones/waylight-r2-2026-10-20.md) 接通林地光叶、镇内备料、水岸造物、双方交接与次日晚间使用。敞亮或有罩的做法具有不同材料、风雨和耗光后果；原存档从空挂点开始。48 小时隔离规则运行走通制作—合作改造—次日使用；新历史检查点压缩后，一万条同类存储负载约 278 MB。真实模型对照和自然跨日仍待 R3/R4。

2026-10-19 本地开发：6A 的时间、等待与后续修正，以及 6B 的四处风语林地点、十二种有限活动已经接入。最新 [蜕壳原野视觉重建](research/milestones/shaping-field-stage6b-shell-v4.md) 将中央聚落与环绕地貌组织在连续曲面上，采用 low poly 三阶卡通光照、细描边、壳状建筑与山脊。新增湿地、旧壳脊与星屑台地目前是视觉地貌，尚未开放新的活动。第六阶段的自然生活质量仍未整体验收。

[第一轮空间与生活呈现打磨](research/milestones/shaping-field-round1-2026-10-19.md) 已在本地实现：弯曲街巷、四类壳屋、温室、镇林过渡与任务驱动细节，附美术参考、前后截图和验证边界。

[R0→R1A 同版本生活观察](research/milestones/world-observer-r1a-2026-10-19.md) 已实现：可恢复源码/存档基线、统一地图/人物/生活/角色快照、断线恢复与实际绘制确认、逐人运行模式。六小时隔离规则诊断暴露补给与等待节奏问题，随后在 R1B/R1C 修正；持续生活质量仍待后续验证。

[R1B 生活轨迹与进餐协调](research/milestones/world-history-r1b-2026-10-19.md) 已接回原存档：版本化增量、检查点重建、冻结历史分页、材料与任务记录，以及六座位进餐和有条件等待唤醒。同一存档的一分钟调度六小时规则对照中，用餐 9→11 次、等饭采样量下降约 20%；个别人首餐仍很晚，生活公平性与自然跨日尚未验收。

[R1C 个人供给与运行观测](research/milestones/life-fairness-r1c-2026-10-19.md) 已接回原存档：持久需要排队、实际备餐/送餐承诺、分阶段灶台占用与并行备料，正式/实验存档分离，调用用量、失败、费用估算与延迟可查。同前态六小时规则对照中，最晚首餐 348→250 分钟、等饭采样 1609→253 人分钟；正常富余前态未恶化。千/万条记录重建与重启通过；其检查点容量问题在 R2 接入无损压缩，长期容量治理和生活质量继续验证。

## 当前能力

| 能力 | 已实现范围 |
| --- | --- |
| 现实时间与有限世界 | 上海 1:1 时钟、天气、风雨昼夜、路线、有限库存、设施占用与持久任务。关闭网页不暂停仍在运行的服务；电脑停机不补造未曾安排的行为。 |
| 多源理解 | 有来源、时效和接收范围的感知；区分目击、听闻、建议、否定、假说和邀请。新闻可以引出问题，不直接成为亲历或物理定律。 |
| 个人认知 | 复用 Asamana 的感知、需要、目标、决策、双流记忆、反馈、反思与关系整理。Python 提出意图，Node 核验位置、条件和后果。 |
| 奇幻规律与共同日常 | 凝光苔、回声杯、余辉夜灯与风语林活动；归途灯新增林地采料、两种制作方法、协作装罩、修补与次日净滤水。规律、材料、任务和 3D 读取同一实际状态。 |
| 关系与共同事务 | 回复关联、明确邀请、接受、拒绝、延期重确认与退出。实际赴约或交接才算完成；个人印象不修改对方记忆或客观关系。 |
| 长期运行基础 | 事件与到期事项唤起；睡眠休息不调用模型；公平排队、最多两名人物并行。个人原文归档、有界热记忆、可重建索引、慢速整理与故障恢复。 |
| 兴趣与机会 | 首次探索、自主返回、受邀、需要与已接受义务分开记录。形成看跨日实际证据；维持看真实可行窗口。离线、缺材料和忙碌不自动等于失去兴趣。 |
| 愿望、试做与采用 | 新认知人物需自己表达角色意愿，再经过既有条件。试做与普通生活共用执行器；采用保留身份，可按形态/职业分轴撤回，不自动更换实体壳。 |
| 生活观察与交流 | 原世界保留聊天入口；回顾呈现为什么、做了什么、实际结果和后续。固定实验、规则回放与正式世界清楚分开。 |
| 连续地形与风语林 | 中央聚落、四周不规则地形、壳体地标、桥梁、湿地、台地与植被群；风语林的安装、测记、风痕、修补和带回夜灯内衬继续读取真实任务与物件。 |

十三名生活角色已经登记，连续调度在隔离测试中覆盖十三人；真实模型对照使用有限人物与小批量情境，没有把十三人全天付费生活当作已完成体验。本机正式世界保留原生活层，新连续认知需显式启用；本轮仅授权发送隔离虚构数据。

第三至第五阶段共记录 974 次提供者调用尝试，峰时价格保守估算约 **¥8.25**，其中两次用量未知保留预留；第五阶段约 ¥2.19。不是账户账单，不含原聊天、旧规划器等其他调用。全系统成本和延迟对照属于下一阶段。

见 [v0.6 验收与局限](research/milestones/asamana-cognition-stage5-v1.md)。当前仍会反复等回应、混淆时区、误解物理规律或在自由文本中多说事实；严格执行器不等于模型每句话都正确。两例预设愿望讨论没有提出新角色，自然愿望的发生频率尚未证明。

## 本地运行

需要 Node.js 24+、Python 3.11+。密钥保存在本机配置，不提交仓库。

```powershell
Copy-Item config\llm_config.example.json config\llm_config.json
notepad config\llm_config.json
Push-Location apps\jev-town-client
npm.cmd install
Pop-Location
.\scripts\start-local.ps1 -StartWeb -StartWorld
```

认知适配器使用短生命周期 Python，无需额外常驻 TCP 服务。用 `DESKBOT_COGNITION_PYTHON` 指定解释器。模型、天气及来源配置见 [本地配置](config/README.md)，实验命令见 [认知适配器](services/deskbot-cognition/README.md)。新下载仓库不继承开发机密钥、正式人生或实验数据库。

## 下一阶段

继续第六阶段：复核 6B 的空间辨识、地点生活链及新地貌的内容准入，验证兴趣与愿望的后续，再比较旧规则、完整认知和优化版的质量、费用、延迟与重复等待；之后做第七阶段小规模自然七日观察。需要包含安静日、中断恢复、昨天留下的后续，以及用户能否看懂改变安排的原因。测试时钟不替代自然七日。

完整人物、美术、表情、声音与打印壳在此基础上联合设计。现实身体没有摄像头或移动能力，只有屏幕、触摸、双麦声源方向、磁识别和单轴转头。当前设备仍为小智固件，DeskBot 实机协议、电机与换壳校准、真实中文 ASR/TTS 尚待接入。虚拟身份不会赋予现实身体额外能力。
