# DeskBot · 聚形域

**让喵呜在桌边拥有持续的生活，由自己的经历与选择，逐渐形成想成为谁的愿望。**

聚形域是伴生于现实的奇幻空间。时间、天气、新闻、主人互动与身体感知经过分级，成为角色能够理解的处境和机会。角色有自己的需要、关系和未完成的问题；实际行动消耗时间与材料，留下可追溯的结果。用户可以参与，输入不会直接改写身份或赠送成果。

**当前进度：A3.2 新冻结复验已执行，R3-A 尚未通过。** 1,399 项离线检查与构建通过；真实原矩阵进入 2/20 窗，1 窗完整有效，第二窗因设想字段类型不匹配停止。实际取水已结算，错误反馈未采用。14 次调用峰时估算上界约 ¥0.32；严格缓存回放一致，未追加调用。见 [A3.2 记录与原始反例](research/milestones/a32-refrozen-acceptance-2026-11-02.md)。

固定隔离上下文的免费对照中，请求由 **29 次降至 25 次**，提示字符减少 **26.85%**；目标形成调用保留。这是预设响应的工程测量，**不是真实费用节省或生活质量验收**。上一轮 [A3](research/milestones/a3-behavior-validation-2026-11-01.md) 仍保留 8/20 完整、7 有效的原结论。

目标与原则见 [开发基线](documentation/development-baseline.md)，接缝见 [接口与调用链](documentation/interfaces.md)，总排期见 [工程交付管线](research/design/engineering-delivery-plan-2026-11-01.md)。**下一步 [A3.3](research/design/a33-command-readmodel-boundary-2026-11-02.md)：分离命令与读模型、完善类型化提示和字段诊断，先做连续读回回归。** 目标专项已准备但 0/16 真实窗口运行，保持未覆盖。正式新认知尚未启用；三人双向生活、地区机制、自然跨日及角色/实体设计仍按门槛推进。

## 已实现的 A2：把“持续生活”落实到同一件事

![A2 隔离规则执行：同一个目标跨夜、换方法与重启，只有一项实际产出](documentation/images/a2-2026-11-01/goal-continuity.png)

上图由 [可重跑的执行记录](research/experiments/a2-lifecycle-2026-11-01/report.json) 绘制：夜里考虑借灯取水，先暂缓；次日仍记得原目标，换用普通净滤。实际完成后得到四份水，SQLite 重启没有重复执行。**行为是人为编排的合同样本，模型调用为 0；时间推进十三小时，不是自然运行一夜。**

| 本轮能力 | 实际约束 |
| --- | --- |
| 同一个目标可以换办法 | 目标 ID、完成标准固定；清水储备允许已声明等价的两种方法，研究条件仍精确区分。 |
| 等待可以跨夜 | 暂缓、恢复、放下均有明确转换；复查时间与社交约定截止分开，睡眠优先。 |
| 完成必须有对应结果 | “任务完成通知”不等于“指定读数已送给指定的人”；开放研究不因一次动作自动结案。 |
| 知道的位置有边界 | 当前亲见、历史位置和实际告知分开；30 分钟陈旧、24 小时位置未知，不窥远处人物状态。 |
| 新旧版本有明确边界 | 新 job 不能省略合同降级；旧冻结实验保留原协议，不补历史证据。 |

实现与扩展方式见 [目标生命周期与位置知识](documentation/cognitive-goal-lifecycle.md)。A2 经 1,385 项自动检查和构建验证。随后 A3 的八窗目标队列始终为空，连续性来自既有问题后续链；新目标建立和生命周期选择仍未得到真实模型覆盖。正式新认知尚未启用。

| A3 观察 | 结论 |
| --- | --- |
| 净滤、测记、装罩、次日展开和休息 | 第一例五窗连续保留原问题；模拟跨日，不是自然运行。 |
| 回执与后续问题互相矛盾 | 库存和回执正确，question 仍可能带入未发生的动作；停止后未追加付费抽样。 |
| 16 次目标调用全部为空更新 | 约 27.3 万输入 token、¥0.536 峰时估算；目标覆盖和按需调用都需补齐。 |
| 调用 / 完整窗口 P95 | 2.463 秒 / 15.121 秒；小样本不外推全镇全天表现。 |
