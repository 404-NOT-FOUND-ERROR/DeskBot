# 第三阶段凝光苔研究与行动变体

喵呜、苔团和灯穗现在可以根据现场条件选择凝光苔研究方法，并按真实材料、地点与时间完成任务。固定小样本验证了连续两回合和受阻后改法；持续多日兴趣仍待第五阶段及自然时间观察。

## 世界规律与实际行动

凝光苔在日间蓄光，夜间消耗蓄光；含水超过 0.65 会抑制显色，较强风会降低凝聚稳定度。规律固定在 `fantasy-inquiry.mjs`，模型的猜想不能改写规律。

十一种活动覆盖健康苗床取样、制作遮风罩、摆明暗对照、间隔两小时测记、等量补水、排湿、装卸遮风罩、对调位置、制作余辉标本和回收试盘。改变条件会重启比较窗口。最多三组试盘；托盘、苔芽与工具均有实际消耗或回收，标本带原始测记出处。虚拟移动沿既有通路执行，远处库存不进入现场视角。

3D 的明暗格、罩体、测记工具、粒子与标本读取同一存档。八个可选片段是执行器固定回放，不是模型自行生活。回放校验修复了同步时钟与逻辑时钟不一致造成的白昼画面错误。

## 模型实验

三个人物分别面对普通和过湿两种前态，各运行连续两回合，共六组、十二次实际任务。首步均先测记；第二步出现再测记、对调、补水和遮风四种方法。三组成对比较中，两个人物改变了第二步方法。每人每前态只有一次，不足以证明统计显著性或稳定人格。

另一次实验在模型思考后、采用前把隔离试架设为损坏。旧测记计划被拒绝，没有生成测记结果；下一回合喵呜实际走到零件屋。后续修复尚未在该案例中完成。

早期失败保留：活动数组编号混淆、基础动作菜单与活动编号混淆。现使用精确活动 ID、冻结引用及有限合同重试。当前七案例未出现非法世界提交；仍有不够准确的主观措辞，需要第四阶段进一步区分观察、听闻、猜想与实际完成。

本阶段含失败及修复验证共 173 次 API 尝试，按峰时价格保守估算约 2.4649 元。第三至第五阶段累计至此 344 次尝试，342 次有用量、2 次用量未知，保留额度后的估算上界约 3.0295 元，并非账户账单。
