# Asamana 认知迁移 · 第二阶段工程与实验记录

记录日期：2026 年 10 月 11 日，上海时区。最小认知生活闭环已接通，隔离实验已经执行；持续生活质量尚未全面验收。正式人物默认不启用本轮付费认知回合。

## 本轮交付

Asamana Agent、Need/Goal、Decision、Memory 与 Reflection 通过本地 Node/Python 接口接入原世界。Node 保存实际任务和 `world.cognition`，Python 不直接改变资源、任务结果、发展证据或形态。固定上游版本、Apache-2.0 与 52 个未修改源文件的哈希保留。

首批能力是已有活动、观察、休息、现场留言、等待。目标与意图由模型提出，执行受位置、设施、材料、占用和时间约束。实际结果与事实原文由 Node 独立核验，解释不增加实践，洞见引用已有私人来源；原文不被后来理解改写。对话读取同一认知状态。

`/cognitive-life-review.html` 显示为什么想做、正在做什么、实际发生什么、还想继续什么，并保留原对话入口。默认隔离实验；正式范围没有加速。测试时钟单独持久保存，支持任务结算、下一复查窗口、下一天。上游认知使用已过整小时，任务与复查使用精确时间。首轮每人最多 4 次安排和 2 次手动反思。

## 真实实验

用户授权首轮最多 CNY 2，允许发送虚构人物、苗圃、实验目标和记忆；没有发送正式聊天和传感器记录。调试原型与修复后的确认轮分别保留存档，共用同一费用账本。

确认轮在同一苔芽圃运行喵呜、苔团、灯穗。第一天三人留下不同问候或邀请；24 小时后，喵呜观察苗床，居民继续回应和邀请。喵呜提出浇水，在下一复查窗口实际选择并完成已有浇水活动：

| 记录 | 实际变化 |
| --- | --- |
| 清水库存 | 12 → 9，消耗 3 份 |
| 苗床水分 | 0.06478 → 0.30362 |
| 苗床健康 | 0.38984 → 0.40651 |
| 后续 | 2 小时后观察恢复，再判断是否照料或留种 |

喵呜的理由指出“苔团说浇过水，但与现场数字对不上”，并依据观测选择照料。最终保留 3 条个人事实、1 条主观经历、1 条引用洞见；两位居民各保留 2 条个人事实，没有强迫普通事件生成洞见。

这证明了一条测试时钟下的“旧交流→次日观察→提出后续→实际浇水→个人理解→继续复查”链，不能代替正式跨日与叙事质量验收。设施占用的受阻、暂缓与材料保护由合同测试验证。调试原型还观察到占用时模型改为回应缺水消息，但该原型不与确认轮合并成一次干净对照。

单次 API 延迟不等于人物整轮延迟；安排与反馈包含多个请求，思考也不等于实际任务时长。小样本无法外推十三名居民全天费用。旧聊天、旧 life-choice 不在此账本里，全系统成本对照仍待后续。

首次同时执行服务和前端回归时，两项时间敏感用例未通过。降低并行、分开重跑后通过，未放宽超时或断言。上述完整服务回归发生在最后的等待调度修复前，该修复由随后 20 项针对性检查覆盖。

发布前生成正式 SQLite 一致性备份：12,746 条记录，SHA-256 `693550bb1c5a696b865e08e3dfc8336122d898c679888b6ff600c843f280ae6d`，integrity_check=ok；原件与备份记录匹配。代码另存发布前快照，旧人生没有替换为样例。

启动时发现旧 mutation 历史约 1.38 GB，被整体反序列化后触发默认 4 GB 堆溢出。现改为加载小索引、按需读取原文，保留完整回放、幂等与冲突检测。服务恢复后实测内存约 270 MB；没有删除历史。磁盘归档策略仍待设计。

本机证据在 `DeskBot Online/runtime/asamana-deployment/stage2/`：`confirmation-final.json`、`final-metrics.json`、测试日志、`ui/verification.json` 和截图。正式确认存档为 `data/cognition-stage2-confirmation.sqlite`，调试原型 `cognition-stage2-experiment.sqlite` 保留，均不替换 `deskbot.sqlite`；本地数据不进入源码公开提交。

## 暴露的问题及下一阶段

1. **无依据发言仍会出现。** 苔团声称“苗床刚浇过水”，却没有对应任务；灯穗把偏干苗况描述为正常。发言没有产生浇水结果或承诺，但仍影响可信度。来源提示已加强，后续要把观测、听闻、假说与完成事实落实到内容合同和生成检查。
2. **时间归因不清楚。** 洞见比较较早观察的健康约 0.43 与浇水后约 0.41；本次任务实际是约 0.39 → 0.41。它作为主观理解保留，不改变事实。执行事实原文现增加开始、结束和本次任务增量，旧记忆不回写；改动仍需后续真实重复实验验证。
3. **社会性等待偏多。** 居民容易反复问候和等回话；尚无结构化答复配对、协商承诺或共同工作过程。发出邀请不等于实际参加活动。
4. **奇幻内容及多源折射未补全。** 普通苗圃能力能执行，凝光苔的蓄光、稳定度、对照试验与 3D 过程仍待第三阶段；天气、新闻、用户建议和旧事的成对因果实验未完成。
5. **长期与发展未验收。** 小规模、有限回合、测试时钟没有证明安静日、长期兴趣、自然愿望或全城稳定费用。与旧 development/facets/wishes 的全面连接按第五阶段开展。

下一阶段先解决来源和行动语义、首条奇幻苗圃规则链，并以相同前态的成对实验检验输入对选择和后续的影响。不能凭接线成功就进入完整角色外壳和美术设计。
