# 第 3 阶段：兴趣、能力和自评连接持续生活

2026-10-06 · 沿用共同经历、十三位居民和有限供给。

本阶段把“遇到过什么、愿意再关注什么、真正做成过什么、因为什么受阻”分开，连接正常生活候选、记忆、原角色方向和侧栏。主人促成的实践也能成为实际能力依据；没有直接变身或建立角色愿望。

## 三日隔离实验

运行 `node scripts/review-development-facets.mjs`，使用新的 SQLite 文件和受控时钟，十二位居民保持暂停，仅喵呜安排生活。起始苗况、清水和饭是明确的虚构实验条件；没有调用模型或外界连接器，没有使用正式数据库，也没有在中途补发资源或写入任务成功。

| 样本 | 观察结果 |
| --- | --- |
| 只听到建议 | 照料接触 1 条，实际结果 0；不产生能力或兴趣加分 |
| 主人促成照料 | 实际配方做成 1 次，受邀 1 次；主动继续 0 次 |
| 三日正常推进 | 留下 157 个共同结果根；照料主动关注 19、受邀 1、需要驱动 8，实际配方成功 9 |
| 其他自主关注 | 制作关注 17、探索关注 19，均没有实际配方能力；观察不能代替动手做 |
| 苗床条件改变 | 开始后在隔离实验移除苗木，到期产生 `crop_absent / condition`，材料归还；能力不足失败 0 |
| SQLite 关闭重开 | 世界身份和发展读模完全相同；重新读取不会增加次数 |

三日经过跨了四个上海日期，但照料关注只来自同一个苗圃观察情境，所以仍为“尝试”，未达到多情境持续投入门槛。照料、制作与探索各加 3 分，其他主题为 0。大量同类观察不等于技能、成熟兴趣或愿望。这是一段受控规则实验，不等于正式世界已真实运行三日，也不证明十三人同时自主生活的长期表现。

实验页面：`http://127.0.0.1:5173/development-review.html?sample=facets`。五个样本由真正的生活循环和到期核验产生，公开数据不含用户配置、私人对白或正式存档。

## 验证与当前边界

自动回归覆盖实际配方归属、主人邀请与动机、每天门槛、急务优先、未知观察、条件失败及退款、旧值冻结、同根去重、任务裁剪后恢复、方向范围、纯读取缓存与回复事实校验。后端最终全套 **553 项通过**；前端 **230 项通过**，类型检查及生产构建通过。语音校验使用模拟合成器验证传出的文本一致性，不代表已完成真实中文发声或实机播放。

真实 DeepSeek Flash 使用三个虚构场景核验：只接触、受邀做成一次、苗木消失导致失败。实际调用发现模型仍可能把收到建议说成已经动手，所以加入有限回复校验，而不把提示词当作保证。最终“只接触”回复明确还没有完成照料记录；一次做成不自称熟练园艺师；条件失败正确指向苗床为空，不编造土太湿。纯校验不增加调用，不写入正式经历。自然表达的其他细节仍需在长期观察中检查，这三例不能证明所有自由回复都准确。

本轮浏览器操作工具在重启后无法启动，因此没有新增界面截图或声称完成新的人工视觉验收。组件回归和构建已完成，正式验收入口保持可访问。

自评目前是规则事实摘要，能力目前是既定配方执行记录。当前还没有作品质量、试吃反馈、复杂操作熟练度、真实中文声音和实机固件适配。本阶段不新增 3D 造型；下一阶段在这些相同依据上实现主动角色愿望、前提和冷却，再进入实际任务试用。
