# Asamana 迁移：2.1 连接补全与 3A 多源理解验收

日期：2026-10-11。对应既定迁移管线的 2.1、3A；3B、4A、4B、5 尚未完成，不据此宣称持续人生或角色演化已验收。

## 本次接通的部分

- 冻结思考开始时的对象、活动、收件人编号映射；对象消失时拒绝采用，不因排序变化换错对象。
- 感知成为独立提交阶段。真实上游 `Agent.perceive_step` 接收有出处的消息，保留听闻性质、原文和来源；普通入账不调用模型、不计实践。忙碌时也能接收，当前任务仍由同一执行器掌管。
- 个人定向关系、已知人物、失败尝试和检索元数据跨 Python 进程恢复。此阶段仅更新实际接触数；信任与承诺没有开放给模型随意改写。
- 实际任务、认知结果和发展证据共享 `task:…` 结果根。观察和交谈使用现有场景动作字段。旧未知动机不补写成自主实践。
- 输入经来源与时效核验后，由模型解释为问题、建议、邀请、报道、假说、否定、引用、问候或无关信息。产物是可选问题、邀请、环境参照、注意或无作用。
- 解释保留原文引证、来源、地点和版本。相同输入在同一地点复用解释；原文或地点改变则重新解释。原始事实不被解释覆盖。
- 解释转为上游 `ExternalGoal`，进入未修改的 `MotivationBlender` 与 `NeedEngine`。不使用 authority 或 obligation；同类消息不会叠加成无限压力。
- 用户 `conversation.input` → 原分级入口 → 新解释 → 后续计划 → 对话读模型已打通，并验证重启保留。轻触或声音方向可以只是留意，不强制催生研究。
- 新统一调用观测覆盖聊天、新闻翻译、连通探测、旧生活选择、新认知和重试。只记录类别、时间、用量和状态，不记录私人提示词或答案。旧历史未观测调用不补造。

## 真实实验

所有输入、人物前态、身体报告和实验记忆均为隔离虚构内容；没有发送正式聊天、设备记录或正式人生。时间是固定测试时钟。DeepSeek Flash 的峰时价格用于保守估算，价格于 2026-10-11 对照[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)复核，实际账单可能更低。

### 预先标注的 32 条输入

标签在调用前冻结，未送给模型。覆盖知识、用户问题、邀请、天气、身体、否定、引用、无关消息、假说和问候。最终一整批 32/32 的作用类别与标注一致；解释阶段没有创建任务、改变资源或增加实践。过期、未来时间、伪造来源、未经设备入口确认的身体输入和重复解释另有不付费合同测试。

该成绩只针对固定小样本，不能推断开放世界准确率。调用参数和提示词仍需要随未来内容扩展继续验证。

### 成对安排对照

三类消息各重复三次，每次固定同一前态，仅切换该输入有／无，共 18 个计划回合。对照条件不是“必须听话”，而是输入能否形成恰当的可选问题，并在实际安排中留下因果来源。

首轮 17/18 有效。一例把未来角色的个人建议分类为共同邀请，合同拒绝采用；修复提示后只重测该例，未重跑已经通过的 17 个回合。最终九组输入侧均在计划和实际任务中引用来源，六组改变了行动类别，其余改变交谈的问题或内容；没有直接改变身份或制造实践。

例如，默认社交问候可以转为观察苔色或征询如何做光照对照。收到苔团的邀请后，回复围绕具体分工。用户提到以后做厨师时，计划仍落在观察或照料植物，并未授予厨师身份。这些任务已提交，但本组没有把任务启动当作长期完成率。

18 个采用回合的耗时中位位置约 6.7 秒，P95（最近秩）约 8.0 秒，包含 Python 启动与多次 API；不是单次 API 延迟，也不能直接外推全天开销。

## 失败、费用及证据边界

保留了两次 JSON 模式提示要求导致的 HTTP 400、费用观测接线错误、轻触错误地被要求生成研究问题、两次编译输出截断，以及上述建议／邀请混淆。修复后增加了定向测试、简短编译字段限制与一次有具体原因的语义修复。没有用替身补齐失败的真实结果。

截至本报告，本轮开发和修正累计 171 次请求，169 次有提供者用量，2 次用量未知仍保留预留金额；累计保守估算 0.56460024 元。这包括失败和旧批次，不包括之前第二阶段约 0.5483 元或原聊天费用。用户授权本轮不设固定金额上限并要求节省；新授权使用独立账本，旧 2 元审批及原记录保留。每个实验仍有批次调用护栏，连续失败先停下定位。

固定验收展示在 [前端证据资源](../../apps/jev-town-client/src/deskbot/cognitive-source-evidence.json)，界面 `cognitive-life-review.html`。可复现实验脚本：[输入标签](../../services/deskbot-cognition/evaluations/source-refraction.mjs)、[安排对照](../../services/deskbot-cognition/evaluations/source-choice-pairs.mjs)。默认只生成出站预览；真实实验必须显式传 `--real` 和本地配置路径。

本地原始预算库、请求轨迹和逐批报告位于工作目录 `runtime/asamana-deployment/stage3a/` 与 `stages3-5-budget.sqlite`。这些包含虚构模型实验文本，公开源码中保留精简证据，不把运行数据库当作源码上传。
