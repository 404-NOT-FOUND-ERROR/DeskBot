# 第八步前的模型与外界输入配置

日期：2026-10-05。保留现有雾灯镇存档、十三个生活角色、实际任务和现实 1:1 上海时钟。此轮不安装长期成长系统。

## 当前启用

| 来源 | 方式与频率 | 当前作用 |
| --- | --- | --- |
| DeepSeek Flash | 官方 Chat Completions，`deepseek-flash`，非思考模式，每次最多 768 输出 token | 真实对话、新闻标题翻译；尚不负责居民高层目标选择 |
| NASA Science | 官方 RSS，每 4 小时检查，每个上海日期最多 3 条，忽略 7 天前的文章 | 保留出处、原始标题、中文译文、发布时间与接收时间，供对话和第八步记忆使用 |
| 上海空气 | Open-Meteo / CAMS 区域模型，每小时检查，2 小时有效期 | 美国 AQI ≥151 时降低露天闲逛意愿，路线可达时增加去室内的候选；保留基本需要和现有任务 |
| 上海天气 | 原有连接器与缓存 | 原有昼夜、风雨、湿润、水位和生活选择 |

新闻不是角色亲历，不创建建筑、物资、性格或行动指令。区域空气模型不是桌面传感器，也不是中国 AQI。空气参考不重复结算雨水或世界资源。模型译文保留原始标题和文章链接；翻译失败时使用原文，新闻来源继续可读。

来源确认来自固定服务端适配器，公开 `/api/event` 不能自称可信。RSS 不解析外部实体，不抓全文，不执行外部指令；请求有时间和体积边界。抓取失败会报告错误并按现有 InputRuntime 退避，不编造成功消息。未成功入场的消息持久保存并以原事件重试；确认投递后再记为已读，重启不会把同一文章当作新经历。

## 本地运行

`config/llm_config.json` 是已有 Git 忽略规则保护的本机文件。仅本机服务读取密钥，保存后下一次请求自动生效；错误不回退为测试回复。`config/llm_config.example.json` 提供无密钥模板。

`scripts/start-local.ps1` 默认启用上述两个公开来源，无需其他 API key。可用 `DESKBOT_NEWS_ENABLED=0`、`DESKBOT_AIR_ENABLED=0` 分别停用；空气坐标沿用 `DESKBOT_WEATHER_LATITUDE`、`DESKBOT_WEATHER_LONGITUDE`。`DESKBOT_LLM_PROBE=1` 会在启动时发送一次短连通测试，不写入对话或成长经历。

只读 `GET /api/model/status` 报告实际模型、配置和验证状态；`GET /api/input-runtime` 保留连接、错误和下一次刷新时间；`GET /api/life/inputs` 与地图的 refraction 读模型展示模型和来源连接状态。页面“现实带来的小事”同时保留消息、空气、天气与未完成建议，避免天气刷新遮住新闻。

此时不需要通用 MCP。直接适配器已经覆盖当前来源，并为未来模型规划保留有限事实和来源记录。后续若接其他 agent 或新增能力，应再设计身份、权限、时效与可验证结果，不把模型生成内容循环灌回外部经历。

## 验证与下一步

服务回归 381 项、前端回归 145 项、TypeScript 检查与构建通过。测试覆盖实际空气候选与真实旅行任务、过期、不抢占任务、消息重启和重试、每日上限、来源链接、读取纯度、密钥重载与失败状态。真实 DeepSeek 短请求已成功，模型为 `deepseek-flash`。

第八步从实际执行记录、关系往来和带来源的消息建立不同的记忆，再让模型在合法行动候选内选择高层目标。仅接上模型不等于已经实现自主学习。真实对话联调也校正了旧场景叙事与执行记录的混用：持续生活问答只采用实际行动，旅行期间仍保留来源新闻，询问喵呜的安排不再误套给用户安排下午的提示。

官方接口依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[NASA RSS](https://www.nasa.gov/rss-feeds/)、[Open-Meteo 空气质量](https://open-meteo.com/en/docs/air-quality-api)。
