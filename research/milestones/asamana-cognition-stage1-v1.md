# Asamana 认知迁移 · 第一阶段验收记录

验收时间：2026 年 10 月 10 日（上海时区）。阶段范围是接口与迁移基线；完整认知生活、真实模型质量和跨日体验仍待后续阶段。

## 已交付

1. `services/deskbot-cognition`：固定上游 `e9fc862642369ba8b177595d2f8e3f20c1636da4`，保留 Apache-2.0 许可证和 24 个未修改源文件的 SHA-256。实际调用 SoulLayer、PersonalityLayer、LLMRouter、IndexedRef 和 extract_json；其余导入依赖不标记为已迁移能力。
2. 四份版本合同：角色可见上下文、认知提案、实际结果、个人记忆提交。Node/Python 使用同一 schema，各自验证，角色、共同根、个人分组、来源、时间与对象版本均有独立检查。
3. 真实 NDJSON 进程通信：Node 在本机启动 Python 工作进程，Python 通过提供者桥请求 Node mock broker，返回提案；Node 核验隔离观察结果后交回 Python，取得记忆提交请求，再以事务保存。
4. 三角色隔离实验：喵呜、苔团、灯穗，共同接收“雨后凝光苔变暗”的样例。苔团另外取得只属于自己的私人样例；其他角色不会收到这条信息。场景绑定既有 `moss-sprout-garden`、`garden-bed`、`seedling-rack` ID，事件和数值明确是合成样例。
5. Node 唯一提交：角色认知版本、采用记录和原文记忆一起提交。独立 `cognition-stage1.sqlite` 不能替代正式存档。个人解释不增加实践、库存、技能或角色采用。
6. 提供者基线：complete / embed 共用 mock 队列，调用前持久化额度预留，记录优先级、延迟、token、缓存、费用、币种、价格版本及使用量来源。付费模式拒绝执行；正式对话继续使用原有配置。
7. 观察入口：`http://127.0.0.1:5173/cognition-review.html`。逐项显示事件可见范围、解释与意图、核验结果、原文记忆、共同根与个人分组、调用账本。既有真实生活观察页增加入口；返回正式世界后交流输入仍可用。

## 当前实际能力边界

本阶段已经证明接口路线可执行、角色视野能分开、提案必须核验、原文可以由 Node 原子保存、索引可以重建、进程中断不会自动补写经历。这是后续接入完整 Python 认知循环的工程基础。

三份解释和目标仍由 mock 程序设定，observe 结果只作用于隔离样例。没有证明居民会自主研究、形成跨日关注或生成更好的叙事。上游 Agent.plan_step、Need/Goal 更新、完整 DecisionEngine、记忆检索排序、关系与反思尚未接入正式生命周期。示例 embedding 是非语义哈希；正式聊天与背景认知尚未使用同一个新队列。正式人生结构本阶段未迁移，未来迁移仍需升级前备份与正式恢复演练。

## 第二阶段的交接

在这些合同与权威提交边界上，接入完整“感受与需要 → 目标 → 可执行意图 → 实际任务结果 → 个人经历与后续”的最小循环，保留分阶段参照，使用同一状态供对话读取。将步数换算、真实时间、私有事实与主观解释适配到既有 autonomy、lived-memory、development facets、trials 与 wishes，避免建立第二套人生。

先确定真实模型/检索适配和费用上限，增加有实际执行条件的活动及受阻改法，再验证隔日继续或放下。奇幻规律、活动内容扩展、3D 痕迹与角色美术分别按后续管线推进；第一阶段不作为进入外壳设计的行为验收。
