# 聚形域进入角色制作前的开发与实验计划

2026-10-07 · 提案 v1 · 软件基线 v0.5 · 对应持续生活路线第二阶段

进入具体角色、主题外壳和完整美术制作前，先验证喵呜能在聚形域中形成有来源、有选择、有后果、可跨日继续的生活。当前基础已经包含时间、任务、资源、共同经历、兴趣分维度、后续和角色发展；本计划补齐这些环节之间的连接及体验验证。以下工作和数值是开发提案，不能作为已实现能力或已通过实验的介绍。

这一轮的完成对象是一段可持续体验的生活：输入改变处境或提出问题，喵呜在有限条件下选择，行动改变具体对象，留下作品、关系或未完成的问题；日后又能主动继续、修改办法、暂缓或放下。角色愿望是可能的后果，不设每周变形配额。

## 当前实现与缺口

10 月 7 日 22:37 上海时间只读检查正式服务，并核对八个相关模块与当前工作副本的内容哈希一致。正式存档保留 612 个共同结果根；最近 24 小时范围内有 155 个结果，其中观察 66、出行 48、休息 31、用餐 5、其他配方 5。喵呜没有主要投入。当时十三人中八人的进食需要超过 90%，三人精力低于 20%。

155 个结果都标为 `need`，但这个字段还包含等候、补给、维护和其他默认计划，不能据此宣称 155 次都是吃饭、睡觉或生存劳动。结果数量也不能代替时间占比：一次几分钟的等候和一次数小时的休息各计一个结果。存档范围包含离线结算和出行步骤，不能当作 155 次独立人生经历。新观察器从当天 21:53 安装开始，只积累约 43 分钟确认在线时间。

现有记录里有两个近 24 小时结果显式关联外界输入，但当前输入记录没有保留下来的选择决定。二者保留范围和生命周期不同，不能据此推断从未采用输入。天气对候选分数的影响也可能没有附带来源引用，显式关联只是影响的下限。

判断：来源多样性值得扩充，当前更直接的缺口是折射、机会内容、安排余裕和表现的连接。先用现有输入验证完整路径，再增接能够提供新问题与新做法的来源。

## 世界需要具备的生活机制

### 聚形域的基本规则

现实时间继续按上海 1:1 经过。光粒凝聚的造物需要一套可理解、可重复观察的世界规律，例如光的蓄积与消散、风雨对凝聚材料的影响、作品的稳定与修复、不同地点的现象差异。首轮只设计一组能运行的规则，不一次铺满六种光域。

奇幻规则规定发生条件、作用对象、变化速度、上限、可观察结果和可能的不确定性。随机性使用可重放的世界随机源或明确的事件参数；天气作用有强度范围和迟滞，不能每次更新就重置现场。玩家可以学习这些规律，居民可以用不同方法研究它们。

规则需要留出生活余裕。食物、休息和维护继续产生后果，但正常供给应能支持好奇、创造与相处。平静的日子、正常重复练习和主动休息都有效；内容安排不能为了制造故事持续破坏设施。

### 输入形成机会

统一记录如下链条，同时允许输入停在其中任何一环：

来源事实 → 有限解释 → 当前关联或问题 → 可考虑的机会 → 实际选择 → 原任务/约定 → 共同结果 → 后续机会与兴趣依据。

来源事实保持原出处与时间，世界内现象遵守聚形域的规则。现实资料可以启发方法，不能替代虚拟世界里的实测结果；听到青蛙的资料不会自动成为青蛙。

区分五种作用：改变环境条件、补充知识、提出邀请、带来作品反馈、重新唤起旧问题。有效期也分层：过期天气停止影响当前环境；由一次实际发现留下的问题可以继续存在，并引用原记录，而不是让旧天气一直作为实时命令生效。

机会至少保存主题、具体问题或目标对象、来源与原结果引用、生成条件、参与者、可用时间、有限做法、阻碍、退出与后续。生命周期区分待条件、可考虑、已选择、执行、结束和过期。复用并迁移已有 `rhythm.opportunities` 的后续结构，不能另建与原后续竞争的生活循环。

### 选择与实际后果

选择综合紧急需要、已接受事务、现场可行性、近期投入、兴趣依据、关系、反馈与尝试新事的成本。先拆硬性约束和可比较偏好，再调参数；单一高分不能同时表示安全紧急、一般维护和作者偏好。

记录主要动机与次要理由，保留受邀来源，并区分谁最初提出、谁决定再次继续。混合动机不删除：做一只托盘既可以补给，也可以比较两种制作方法；后续自主选择的证据来自当时真实可选项和实际执行，不靠重新标记旧任务。

每个实际结果继续使用原 `root_outcome_id`。作品增加稳定对象标识、制作批次、做法、可核验属性、去向和使用结果；不同人的记忆与评价引用同一个结果，解释可以不同。完成配方、作品质量、喜欢这件事和想成为某种角色分别判断。

### 连续性与变化节奏

当下状态、近期关注、兴趣投入、项目关系、角色愿望采用不同时间尺度。主要投入维持与新兴趣形成采用不同条件，避免窗口过期就删除偏好；条件困难、忙碌和明确放下分别处理。

比较的情境要有实际差别，例如对象、做法、同伴、环境或反馈。只换地点、换标题和重复讲同一结果，不增加独立证据。更换主要投入的判断读取真实选择和可用机会；缺少机会不能解释为不再喜欢。

已有愿望、试做和双轴采用读取同一生活依据。先验证普通生活可以达到前置条件，再调整门槛；明确拒绝、暂缓、采用后回看和回退继续有效。不能用降低门槛或补写实践，掩盖行动内容不足。

## 进入制作前的工作顺序

以下 P0 至 P7 是现有第二阶段的细分工作包，不替换旧 v0.5 角色工程编号。每个工作包都交付代码/内容、可体验入口、实验结果与已知限制；本文件目前只确定提案。

| 顺序 | 工作与交付 | 进入后续工作的条件 |
| --- | --- | --- |
| P0 基线与测量 | 校正动机口径；记录任务区间、可行候选、阻碍、决策来源、输入各环节、模型额度；升级观察面板和隔离实验导出 | 能区分没有内容、内容不可行、没被考虑、没有选择、任务失败与表现缺失；不把离线结果计为在线生活 |
| P1 世界规则与内容合同 | 设计首组凝聚/环境规律；将活动卡转为可校验登记；定义问题、机会、作品、观察结果与后续引用；保留专门执行器 | 一个现有地点中的奇幻活动能产生真实对象变化，成功、受阻、拒绝、重启有完整过程 |
| P2 分级折射与来源组合 | 接通环境、知识、邀请、反馈、唤起五类作用；补普通对话语义解释；现有新闻匹配登记的问题/做法；按内容需要补自然和艺术来源 | 有效输入影响机会或条件有引用；未知内容可保留为话题；重复来源不叠加优先级，也不改人格 |
| P3 生活余裕与选择安排 | 根据 P0 定位供给、疲劳、队列和任务占用；区分紧急与一般事务；处理承诺、中断和公平；扩展有意义的自主尝试 | 可用资源下能恢复；闲时确有选择空间；原项目和少数角色不会长期垄断设施、余裕或模型额度 |
| P4 三条奇幻生活内容链 | 完成苔圃、水岸、夜间研究的发现、比较、制作/观察、反馈与跨日后续；深化既有居民分工；补实际场景变化、动作、对话与回顾 | 用户能看到同一件事的前后变化，实际合作有分工和共同后果；至少一条链贯通主人参与与自主继续 |
| P5 兴趣稳定与角色可达性 | 按有意义情境区分接触、受邀、主动继续、能力与评价；检验主要投入、搁置、唤起、分歧、退出；在隔离世界走愿望/试做/采用 | 投入既能形成也能合理维持或放下；条件受阻不会冒充失去兴趣；角色前提可达且不能被重复消息刷过 |
| P6 对照实验与真实观察 | 各工作包持续做隔离对照；内容链齐备后完成消融、压力实验、七日在线试运行及小规模体验评审 | 发布实验范围、失败案例、覆盖时长、成本与体验问题；五项生活门槛成立，关键问题有处理结果 |
| P7 角色与结构设计交接 | 从真实生活提炼一个角色设计简报：保留身份、愿望依据、采用后实际行为、屏幕表达和实体限制；开始完整造型与外壳联合原型 | 软件生活、表达方案、机械尺寸与打印验证分别有依据；不把虚拟预览等同于实体可装配 |

P0 的测量贯穿后续全部工作。P1 首条活动是贯通用的功能原型，P4 才深化三条内容链。P2 与 P3 的对照可以使用同一批隔离世界；观察在整个开发期间持续，但不同版本分开报告。

P4 包含场景概念、布局、工具、状态材质、动作和信息呈现。它们是检验生活的必要表达，提前制作功能原型；最终角色风格、完整角色模型和可打印主题壳在 P7 后推进。硬件测量清单、现有 STL 包络分析与核心结构草模可以同步准备，真实尺寸和打印件仍需实测。

## 第一批奇幻内容链

以下为待评审的新内容示例，首轮依托现有地点，不立即增加大量地图和 NPC。新增对象与效果必须先登记执行规则。

| 内容链 | 现实与世界内起点 | 居民的不同选择 | 持续后果与画面 |
| --- | --- | --- | --- |
| 苔圃的凝光研究 | 天气作用于已有水分；发现两簇虚构凝光苔的蓄光表现不同；主人或自然资料提出比较问题 | 观察、遮光、调整种植方式、请同伴比较、先照料或暂缓；不同方法有各自材料与耗时 | 保存批次和观察记录；次日复测、制作试用灯、反馈后修订；画面能辨认样区、蓄光与消散、工具、真实成果 |
| 水岸的风织作品 | 风影响登记的风弦/光带；已有声音主题关注、工艺资料或朋友作品引起好奇 | 录取虚拟现场声纹、比较位置、搭风弦、编光带、分享、因风太强转室内做；同伴可有不同偏好 | 留下可使用的作品及作者、方法与版本；天气变化后复用或返工；能看见弦的运动、作品在场和具体反馈 |
| 夜间的星潮问题 | 聚形域按现实时间运行的虚构夜间现象；科学资讯提供联想；白天准备时留下问题 | 傍晚短观察、隔天比较、设置观测器、请朋友带回记录、决定睡觉；无需熬夜才能获得发展机会 | 现象、观测与推测分别记录；问题逐渐收束或改写；窗口、灯光和设施运作同实际状态一致 |

前两条深化已有苗圃与水岸；第三条先验证现有场地，确实缺少空间时再增加一处小型观测场。新场景必须带来新的可执行问题或方法，并配齐通路、开放时间、设施容量、天气作用、任务表现与存档兼容。

苔圃可连接照料、探索与制作；风织可连接制作、修缮、探索与相处；夜间研究可连接探索、工具制作与合作。一个地方不固定对应一种角色愿望，一个兴趣也不固定只在一个地方发生。

共享作品与问题可以逐渐形成居民自己的话题与习惯：一人提出做法，另一人试用，第三人不同意，后来的邀请引用此前结果。文化感来自持续传播和共同后果，不由系统直接宣布“镇上形成了一种文化”。

## 多源输入怎样扩充

来源按作用和可用内容组合，先控制数量和关联质量。新闻只是其中一类，世界内现场、项目反馈和关系邀请同样重要。

| 来源 | 当前与新增顺序 | 能影响的内容 |
| --- | --- | --- |
| 时间、天气与空气 | 保留现有连接；补积极机会与来源追踪；数据中断保持未知 | 自然过程、可行窗口、室内替代、比较条件；限制强度与持续时间 |
| 主人交流 | 补问题、兴趣分享、邀约、作品反馈、否定与纠正的有限语义合同 | 关注、机会、反馈和关系；可以拒绝、暂缓和提出自己的做法 |
| 科学资讯 | 先让当前 NASA 来源接到实际问题，不增加资讯数量配额 | 探索、比较与方法联想；来源事实与虚拟试验分开 |
| 自然知识 | 内容需要时试接一个来源；GBIF 物种接口可作名称与分类查询候选 | 相关生物主题的资料接触；生物行为和栖息规律另需可靠资料，不能从物种名推断 |
| 艺术与工艺 | 内容需要时试接一个来源；芝加哥艺术博物馆馆藏接口可作候选 | 作品、作者、材料与工艺主题的联想；具体方法仍经过已登记活动 |
| 居民与世界内现象 | 优先扩充实际现场记录、作品使用、邀请和共同问题 | 不同理解、分工、求助、后续与共享成果 |
| 身体与其他 agent | 保留现有边界；小智固件适配与真实 agent 服务分别联调 | 注意转移、有出处的提议与已校准壳状态；目前样本不能称为实机感受 |

外部候选依据官方 [GBIF API 文档](https://techdocs.gbif.org/en/openapi/)与[芝加哥艺术博物馆 API 文档](https://api.artic.edu/docs/)。前者提供物种与观测资料接口；后者提供馆藏查询及公有领域筛选，图像与描述的使用范围须按各自字段核验。本轮只确认候选，中文质量、连通、缓存、限流与映射实验通过后才安装连接。

首轮至多新增自然与艺术各一个来源，和现有资讯共享注意预算。每条来源设置独立去重、事实时间、语义相关性与冷却；一次高相关的问题可以多次产生实际后续，而不是靠不停推新标题维持生活。

模型负责有限解释与比较理由，服务验证结构、权限、主题、对象和方法；未知意图不执行。低置信或有歧义的建议可以解释或向用户确认，不把所有普通话语都转成任务。

MCP 可以以后作为只读资料接入方式，与 HTTP/RSS 使用同一来源合同。它不会自动增加生活可能，首轮沿用现有连接器，更容易做来源和折射的独立对照。

## 测量口径

P0 记录决策时的候选及当时阻碍，不能事后用当前世界状态猜过去为什么没做。在线任务时间按演员与区间取交集，重叠区间去重，暂停和不可观测间隙单列；睡眠不计入清醒生活分母。多人共享事件按每人实际参与角色统计，同一共同根不能反复充作独立实践。

| 指标 | 分母和范围 | 判断用途 |
| --- | --- | --- |
| 来源与折射覆盖 | 已接收、可信、时效有效且属于登记范围的输入；与无关/过期输入分开 | 哪些只能聊天，哪些生成问题、改变条件、形成机会；不能要求每条新闻都改变生活 |
| 机会到行动漏斗 | 生成 → 实际可行 → 到达可安排窗口 → 被考虑 → 被选 → 开始 → 结算 → 后续；每层有数量、原因及时间 | 定位来源、内容、排期和执行的瓶颈，避免仅看任务完成率 |
| 因果影响 | 成对世界中同一前态，加入/移除某输入前后的条件、候选或选择差异 | 有出处只证明关联；反事实对照才能支持影响判断，不要求都选择输入建议 |
| 生活时间 | 每人确认在线、清醒时间；必要生活、等待、履约、自主投入和受邀实践的实际时间 | 检查余裕与等待挤占；动作数量和文本长度不作替代 |
| 有意义的选择空间 | 非紧急、无既有任务/承诺占用的决策窗口 | 至少两种改变对象/方法/关系后果的可行选择；休息保留但不单独凑满多样性 |
| 连续性 | 已参与项目和已选择的后续；仅计算条件可行、曾有安排窗口的部分 | 下一日实际继续、明确暂缓/拒绝/结束及对应原根；不可行不等于不感兴趣 |
| 兴趣节奏 | 每人已知动机的实际实践和有意义情境；按上海日与机会可用情况报告 | 形成、维持、搁置、唤起、主要投入更换；接触与能力单独列出 |
| 反复与卡住 | 同一目标、对象、做法、结果和阻碍连续重复的窗口 | 排队耗损、长期高优先级垄断；正常照料、练习与睡觉不按重复失败处理 |
| 模型运行 | 请求、解析、超时、回退、演员预算、token、费用、延迟 | 有无角色饥饿或旧候选到达太晚；记录选择服务与对话服务的预算范围 |
| 用户感知 | 已知真实状态下的短看与隔日回访任务 | 能否看懂当前活动、指出昨天的后果、理解理由，区分意图与已经发生 |

### 首轮检验目标

以下是试验前设定的设计假设，先在隔离案例检查可达性，再用试运行决定是否调整。不能把这些数值写成程序强制行为或普适人格标准。

| 项目 | 初始目标或报警条件 |
| --- | --- |
| 世界与证据一致性 | 所有验收案例均通过库存/预留一致、引用有效、共同根不重复、读取无副作用、重启兼容；旧动机未知保持未知 |
| 折射可用性 | 至少 30 个事先标注的在范围内、条件可行案例中，80% 能产生正确机会或条件变化；歧义、否定、引用与无关输入另列，未授权/重复输入不得绕过合同 |
| 因果影响 | 固定前态、固定其他输入的正向与限制类对照中，至少 80% 出现预定方向的机会/条件差异；行动采用率只观察，不设顺从目标 |
| 选择空间 | 清醒且非紧急、无既有占用的窗口中，至少 70% 有两种实质不同的可行选项；按演员和场景分别报告 |
| 生活余裕 | 先以正常资源条件下 20% 至 40% 清醒在线时间可用于自选投入作调参参考，并报告个人差异；不强制行为配额 |
| 等候与恢复 | 正常供给案例中，不允许有可用恢复路径仍持续 6 小时未推进的高需要等待；异常缺料或不可达另列，窗口是报警阈值，不是既有实验结果 |
| 跨日后续 | 至少 10 件已选择且后来可行的后续中，60% 在窗口内实际推进或有明确暂缓/放下；剩余逐件诊断，完成与解释分别列出 |
| 兴趣变化 | 同一人一周更换主要投入超过一次进入复核；长期没有主要投入也检查机会，不直接判失败；不限制正常旁支尝试 |
| 可感知性 | 小规模体验评审中，至少 80% 的有效回答能指出真实当前活动与一项前后后果；错误宣称已完成须逐件修复，安静日也纳入评审 |

分母不足时标为证据不足，不能将 1/1 写作稳定通过。体验分数、兴趣稳定与奇幻感仍需解释性评审，不能由这些比例自动决定验收。

## 实验顺序与对照

### 规则与迁移实验

每个工作包先验证成功、条件受阻、取消、失效、重复输入、版本迁移与服务重启。持续检查库存/容量、材料预留、路线、已接受承诺与共同根。实验使用存档副本或构造世界，禁止写入正式经历或免费补写成果。

加速只改变实验时钟的推进速度，活动耗时、资源变化、天气有效期和跨日规则保留原单位，经过同一结算器；它用于检查规则稳定性，不能称为现实已经生活了这些天。

### 多场景持续推演

第一轮每个方案使用 20 个不同初始世界/随机种子，各推进 7 个实验日，覆盖正常余裕、恢复期、材料缺乏、连续风雨、来源中断、稀疏互动、密集重复建议与协作占用八种场景。每个方案为 1,120 个世界日；与一个基线成对对照为 2,240 个世界日。先用小批次估计运行成本，再决定批量规模；种子是隔离世界的随机性，不等于保证模型可复现。

控制组与改动组使用相同前态、环境事件序列和来源样本，保留当前兴趣与愿望门槛作基线。复杂社会行为的失败要追溯到任务与对象，不用总平均遮盖少数长期没有机会的居民。

规则实验使用确定性选择或明确的模型替身；真实 DeepSeek 另外选取少量固定场景，每个条件重复 5 次，观察理由有效性、选择分布、延迟和成本。实际调用总数、token/费用上限在运行前登记，多个新解释服务不能绕过预算。现有生活选择限制为每小时 6、每上海日 72 次、演员尝试间隔 120 分钟，它们不是整个项目全部对话的额度。

### 定位来源与折射的作用

首轮使用两因素对照：来源组合为“现有来源 / 加自然与艺术来源”，折射为“当前映射 / 新映射”。四组保持内容、输入数量预算、前态和天气序列一致。这样能区分来源带来的话题差异和转换规则带来的行动机会。若沿用完整八场景、二十前态、七实验日规模，四组为 4,480 个世界日；这是规则推演规模，不包含按每个决策调用真实模型。

再分别移除跨日后续、作品使用反馈或关系邀请，观察生活链在哪一层断开。对照移除机会提供，不删除既有经历、不把别组的结果移植进来。每次只改目标因素，避免一次增加地图、人物、模型和阈值后无法解释效果。

每组报告每个隔离世界的指标和分布、配对差值、异常样例及不确定范围；统计区间以世界为重复单位，不能把同一世界中的数百个相关任务当作数百个独立样本。结果支持工程设计判断，不自动声称证明心理学意义上的自主性。

### 正式运行与体验评审

每个发布版本继续自动观察；内容链和主要缺陷修复后，安排至少七个有记录的上海日期，明确每日在线覆盖与停机，并覆盖白天活动、晚间变化、正常休息、次日继续和至少一次服务重启。短暂跨午夜不足以替代跨日生活；关键情境没有覆盖时延长观察，不能按七个日期自动通过。每天自动整理必要生活、自主投入、输入改变、原事后续与可见现场，用户只需偶尔交流、看一眼和隔日回来；无需手工记账。

邀请少量体验者（首轮 3 至 5 人，可先由项目参与者完成）做四类任务：30 秒理解此刻、隔日辨认后续、提出普通建议并理解回应、经历一个平静日。问“它在忙什么、为什么、昨天留下了什么、我的话如何影响它”，也记录是否感到有自己的生活、是否看不懂或像重复播放。

输入与结果引用用于核验，评审记录保留匿名汇总。该规模能发现设计问题，不足以代表所有用户。若只有设计者评审，明确标注，不能写作多人体验验证。

## 进入角色与外壳联合设计的验收

满足以下条件后，提出进入下一阶段的具体交付和证据，由用户验收；不按工作包数量自动宣布完成。

1. 普通资源条件下，基本生活与服务恢复能够运行，持续高需要、设施争用与长等待有原因和处理；安静、睡眠与停机分别展示。
2. 环境、主人交流、知识或世界内反馈能通过不同作用路径影响实际选择；至少一条知识/邀请路径和一条环境路径有可追溯的行动过程，同时展示一次合理暂缓、拒绝或失败。
3. 至少两条不同主题内容链留下作品、问题或关系后果，喵呜在真实跨日记录中出现基本需要之外的主动继续；不是只有构造样本或固定作息巡点。
4. 用户通过场景和交流可以理解当前行为、过去后果和未来意图；逐条核验回顾引用，生活感与奇幻感均有体验评审记录。
5. 隔离实验确认一个角色方向能由合法生活达到前提、提出愿望、完成实际试做和采用，重复或虚假输入无法刷过；正式生活不要求七日内一定提出愿望。
6. 实验、自然运行和版本记录分清，数值与失败样例可复核；硬件测量缺口、固件未接通和打印约束进入交接清单。

交接时选择一个与生活内容相连的方向做完整原型，保留形态与职业的双轴组合。机械约束来自屏幕、头顶双麦克风开孔、声学/散热、触摸、接口、装配维护与单轴旋转避让；猫耳等当前特征是可讨论的造型，而不是未经测量的强制锚点。

## 下一次可执行交付

从 P0 开始，完成决策与时间口径、输入漏斗和断链诊断；同时用现有输入与内容卡写出苔圃一条完整案例。首次交付应让用户看到“某条输入停在哪一步、为什么、什么活动能补上”，并给出修复前的隔离基线。随后 P1 才实现首条奇幻规则与活动原型。

不把“再等几天”作为唯一下一步。观察为修复提供依据，测量、规范、折射和内容需要主动开发。
