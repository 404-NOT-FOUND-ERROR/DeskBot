# 自动生活、模型与外部输入边界

**当前功能基线：v0.5 · 角色发展第 6 阶段，2026-10-07。** 自动生活由程序设计的有限规则与模型选择共同完成。模型参与表达与合法选择，世界状态、材料、时间和角色阶段由服务端核验与提交。

## 自动生活与模型选择

| 环节 | 当前职责 | 权限边界 |
| --- | --- | --- |
| 现实钟与世界任务 | 按上海 1:1 时间恢复任务、检查期限和结算结果 | 生产世界不能通过模型或研究快进改变经过的时间 |
| 需要与合法候选 | 根据食欲、精神、地点、天气、材料、已有任务、关系和兴趣生成选项 | 必须保留基础需要与已承诺事务的优先级 |
| 有限闲时模型选择 | 当前事实和有限候选供 DeepSeek 选择；记录请求、结果、执行核验与回退 | 不开放任意目标、工具调用或 world mutation；失效选择使用规则回退 |
| 实际任务执行 | 原旅行、配方、材料预留、活动耗时、容量与结果结算 | 模型台词不能替代动作或赠送库存、技能与成功 |
| 记忆与角色发展 | 同一结果进入事实/消息/理解、发展维度、愿望、实际试做和采用依据 | 接触、能力、兴趣和愿望分别判断；模型回复不回灌为亲历证据 |
| 当前角色阶段 | 保存形态与职业两个当前轴，投影到有限生活、表达和 3D | 纯预览不写入，明确采用需真实依据；回退保留已经发生的后果 |

只读 `GET /api/model/status` 可区分对话配置和 `dialogue_and_life_choice`；`GET /api/life/autonomy` 展示实际策略与近期生活。配置了 DeepSeek 不等于所有行为都由模型自由产生。

## 对话编排

用户文字、最终 ASR 或设备回合触发 `chat-orchestrator`。它读取有限最近对话、当前世界、短状态、来源、实际记忆、愿望与双轴阶段，组装角色提示。服务调用配置的 Chat Completions，模型只能返回语言与受限选择，没有直接写 SQLite、角色身份、外壳或设备权限的能力。

对明确发展和采用状态提问，程序据当前存档进行有限事实校准。屏幕回复、mock TTS 检查与设备文字共用校准后的答语；模型原稿留在本地审计。该机制不保证所有话题都已可靠，持续表达仍需真实对话与人工观察。

事件与 correlation 保持幂等，provider 失败返回结构化错误，不回显上游响应或密钥。实际模型、配置与连接验证状态从 `/api/model/status` 读取。

## 现实来源调度

| 来源 | 当前适配方式 | 调度与生活作用 |
| --- | --- | --- |
| 上海天气 | Open-Meteo；也保留 QWeather v7/v1 适配器 | 观测与预报分别缓存，TTL 到期刷新；观测影响风雨、湿润、水位及候选，昼夜来自现实钟，明确要求最新可绕过缓存 |
| 自然与宇宙消息 | 固定 NASA Science RSS | 每 4 小时检查，每上海日期最多 3 条，忽略 7 天前文章；保留原题、译文、出处与时间，作为消息进入记忆 |
| 区域空气参考 | Open-Meteo / CAMS | 每小时检查，2 小时有效；美国 AQI ≥151 时减少露天闲逛、增加合法室内候选，不抢占现有任务 |
| 主人互动 | 文字、触摸、触屏与明确建议 | 分开记录接触、主人促成的实际实践与后来自主继续，不能仅凭建议改变身份或证明能力 |
| 其他 agent | 服务端来源适配与输入合同 | 已有来源、时效和权限入口；当前未默认接入外部 agent 服务，也未向模型开放通用 MCP 写权限 |

NASA 标题可经模型翻译，失败保留原文。来源正文不是行为指令，新闻不是亲历，区域空气不是桌面传感器或中国 AQI。天气失败保留原时间的快照；InputRuntime 持久保存待投递、结果与失败退避，重启和重试不会重复制造经历。

`scripts/start-local.ps1` 默认启用 NASA 消息与空气参考，使用 `DESKBOT_NEWS_ENABLED=0`、`DESKBOT_AIR_ENABLED=0` 可分别停用；空气坐标沿用天气配置。当前工作站天气来自上海 Open-Meteo，其他部署以 `/api/input-runtime` 和连接器状态为准。配置见 [本地配置](../config/README.md) 与 [变量](variables.md)。

## 愿望、试做与采用

程序读取共同结果与分维度依据，达到前提和冷却后才提出有理由的角色愿望。主人支持只记录准备，之后仍要完成原生活任务。当前试做方式在当前回顾窗口内跨两上海日的两项主要成功、正向成功回顾、匹配原愿望和明确采用共同决定阶段准入。

当前闭集造型为荷叶青蛙、工坊学徒、灶边厨师。形态与职业可组合，采用封存原试做并更新唯一阶段档案。采用只增加合法日常选项和造型，不提供食材、技能或资格；饥饿、休息、任务和约定仍优先。回退只恢复对应当前轴，不撤销人生经历。详见 [阶段规则](../research/world/role-stages-v1.md)。

## Voice sidecar

配置 `DESKBOT_VOICE_SIDECAR_URL` 后，Node 才调用 `/v1/asr`、`/v1/tts` 与 health/capabilities/cancel。只有 final ASR 进入一次用户回合；TTS 读取同一校准答语，音频工件须核验格式与 hash，sidecar 没有世界写权限。

当前正式部署未启用真实 sidecar，checked-in worker 为 fake/model-free 合同基线。真实中文 ASR/TTS 与人工试听是第 7 阶段。未配置时接口明确报告不可用，不能把模拟音频写成真实语音已连通。

## 身体与设备输出

身体输入要求本机登记与能力交集。触摸提供短时注意和空闲候选；双麦方向需坐标质量与正前校准，未知磁读数不猜外壳。受限单轴 yaw 经过范围、冷却、忙碌与期限检查，再交给唯一 outbox。

WebSocket bridge 只发送设备协商支持的命令，并核验 command ID、绑定、期限、ACK、帧长与序列。命令发送、设备报告、执行失败与实测结果分别保留；重传不重复执行，软件意图不冒充动作成功。

设备当前仍是未适配的小智固件。软件感知与模拟回执已实现，实体屏幕、触摸、地磁、双麦方向和底座动作留待第 8 阶段。当前有限虚拟角色采用也不会改变实体外壳、声音或电机能力。

## 当前验证与后续

规则回归和受控 SQLite 样本已经覆盖世界到阶段的接入；真实模型仅完成有限状态摘要验证。浏览器新阶段像素验收、真实声音、硬件闭环和自然 7–14 天连续观察尚待完成。详见 [测试与实验](tests.md) 与 [开发路线](../research/development-roadmap-v0.5.md)。
