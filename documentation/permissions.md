# 权限与信任边界 · v0.5 第六阶段

DeskBot 当前是本机原型，服务保存唯一持续世界、任务结果与角色阶段。权限主要由输入来源、事件校验、设备绑定、受控服务路径和世界执行规则实现；HTTP 接口仍没有完整用户登录、多租户或角色授权。默认绑定回环地址，不能把现有规则校验等同于公网访问认证。

## 当前职责

| 资源或操作 | 本机 Web / 用户 | 已绑定设备 | 外部 provider / agent | LLM / sidecar | 服务执行边界 |
|---|---|---|---|---|---|
| 读取世界、来源与阶段 | 读取投影 | 读取协商需要的信息 | 无任意读取权限 | 只读提供的上下文 | 世界、任务和当前阶段来自服务存档 |
| 用户文字 / 最终 ASR 回合 | 可提交 | 按协议提交 | 不能冒充主人 | sidecar 仅返回 ASR 候选结果 | 事件、身份、大小与幂等校验；最终 ASR 才计回合 |
| 身体感知与动作回执 | 不能冒充实机 | 通过绑定连接与登记能力 | 不能冒充设备 | 无设备事实写权限 | 感知、命令、派发与 ACK 分开；未执行不声称已执行 |
| 外部天气、新闻及空气资料 | 可请求或查看 | 可由对话请求相关上下文 | 经配置 connector / 受控来源提交 | 可读取筛选后资料 | 保存来源、时间、有效期与资料类型，有限折射进入处境 |
| 世界任务与资源变化 | 可通过受限操作请求 | 只走设备事实路径 | 不能直接提交世界后果 | 不能自行执行或写结果 | 服务核验路线、材料、设施、容量、耗时与原任务结算 |
| 闲时生活选择 | 可提供影响与建议 | 感知可影响合法候选 | 可提交受控来源影响 | 只选服务提供的有限候选 | 基本需要优先；选择过时、失败或非法时回退规则安排 |
| 愿望、实际试做与正式角色阶段 | 可回应、控制试做、预览、明确采用和分轴回退 | 不能直接写阶段 | 不能提交成果或阶段 | 不能以回复生成愿望依据或正式阶段 | 原愿望、实际结果与当前版本核验后，经内部阶段引擎写入 |
| 确认记忆、承诺与作者计划 | 按相应界面明确保存或操作 | 不从普通设备事件推断 | 不从来源文字推断 | 回复不能自动创建确认记录 | 专用 API 校验，报告与模型解释保留独立事实边界 |
| 音频工件与设备输出 | 可通过服务触发和读取 | 验证后消费、回执 | 无写权限 | sidecar 提供候选音频 | 工件格式 / 哈希、绑定、过期及 ACK 幂等校验 |

本机研究 API 仍可进行作者修改，因此“可提交”不意味着已具备不同用户之间的访问隔离。`source` 或 `source_kind` 字符串本身不能授予服务内部角色阶段或实机回执权限。

## 正式角色阶段的专用边界

第六阶段的权威存档为 `world.role_stages`，保留形态 `form` 与职业 `vocation` 两个当前轴及版本历史。提案决策用于记录原愿望和主人回应，不能替代当前阶段事实。

- **原始依据：** 保存的生活愿望须与实际试做相符。当前试做方式、当前回顾窗口内至少两项不同的主要完成结果，需横跨两个上海日；服务核对原任务准入、结果与冻结的愿望依据。准备步骤、取消、困难回顾、旧方式结果和模型解释不能替代这一条件。
- **纯预览：** `GET .../stage/preview` 只读造型和生活变化，不修改存档、任务、库存或当前阶段。当前选项是有限作者方案，客户端不能上传任意外观或阶段效果。
- **明确采用：** `POST .../stage/accept` 提交预览指纹，服务再次核对两轴版本及原始结果。过期预览需刷新；公开接口不能自报经历、技能或成功结算。正式写入只走核验后的 `role-stage-engine` 内部执行路径，普通 `/api/event` 不能绕过。
- **双轴与回退：** 只能回退对应轴的当前版本，恢复前一版本或基础状态，另一轴继续。已经发生的经历、关系、材料消耗与现有任务保留；已用于采用的试做封存，不重复消费同一批成果。重复事件与重启恢复不重复执行。
- **虚拟与实体：** 采用改变虚拟造型层、有限生活选项和表达上下文，不改变持续身份、实际外壳或设备能力。它不授予材料、技能或职业资格，不证明情感喜欢与作品质量。

早期聊天反馈的 accepted `role-state.v1` 记录仍保留兼容与历史用途，不能冒充新阶段采用依据。LLM 可以表达已核对的当前状态，但模型台词不写阶段，也不能将历史阶段说成当前阶段。

## 模型选择与规则执行

DeepSeek 闲时选择使用服务当前生成的有限合法候选和有边界的生活记忆；模型只能返回候选选择与说明。服务保留请求、版本与结果核验，再交给原世界任务引擎执行。基本需要可优先取代旧想法，非法或超时选择可回退；模型说“已完成”不产生任务结果。

模型解释不是新的独立成长证据。实际任务、共同活动与原始结果经过统一账本后，才可参与兴趣侧面、愿望和试做门槛。受控外部 agent 输入也不能直接改写世界、主角身份或角色阶段。

## 配置、语音与实机

密钥只由服务读取本地文件或环境变量，不进入客户端、SQLite 事件、公开响应或日志。启用外部 LLM 后，聊天和闲时选择的相应提示文本会发送到配置端点；生活选择使用已筛选的模型上下文，不能据此假设所有聊天均不含用户输入。

语音 sidecar 无世界写权限；音频协议与软件模拟不证明真实 ASR/TTS、实体播放或转头成功。当前小智固件尚未适配 DeskBot。头部触摸、屏幕触控、换壳感知与声音方向按设备合同接入；无摄像头、实体移动或新增自由度。
