# DeskBot Web · v0.5 第六阶段

聚形域的文字体验与研究客户端。它调用 `apps/deskbot-service` 的 HTTP API，展示喵呜的对话、现实输入、生活记录、愿望、实际试做和角色阶段。服务保存唯一世界状态；本页不读取密钥或维护另一份世界存档。

日常生活的主要 3D 入口在 `apps/jev-town-client`，本页保留文字体验与可审计操作。产品当前为 **v0.5 第六阶段：实际试做后的可逆角色阶段**；本目录内部包版本独立维护。

## 启动

需要 Node.js 24 或更高版本。从仓库根目录按 [本地配置说明](../../config/README.md) 准备 LLM 配置后：

```powershell
.\scripts\start-local.ps1 -StartWeb -StartWorld
```

- 文字体验与研究台：<http://127.0.0.1:4322/>
- 聚形域 3D 世界：<http://127.0.0.1:5173/?mode=deskbot&deskbotUrl=http://127.0.0.1:4311>
- 第六阶段独立样本：<http://127.0.0.1:5173/development-review.html?sample=stages>

服务已在 `4311` 运行时，也可在本目录执行 `npm start`，单独打开本页。可选环境变量为 `DESKBOT_WEB_PORT`（默认 `4322`）、`DESKBOT_WEB_HOST`（默认 `127.0.0.1`）和 `DESKBOT_SERVICE_ORIGIN`（默认 `http://127.0.0.1:4311`）。停止组合服务使用仓库的 `scripts/stop-local.ps1`。

## 当前体验与能力

- **文字与生活上下文：** 对话使用服务端当前状态、现实时间和有来源的生活切片。页面展示地点、世界事件、附近居民、关系与确认过的记忆，未知或尚未发生的内容不当作完成结果。
- **现实输入：** 显示上海时钟、天气来源与新鲜度、预报缓存和连接状态。当前软件包含公开新闻及区域空气来源；是否启用、是否连接成功以服务返回为准。手工研究输入仍明确区分于网络观测。
- **有依据的方向：** 研究视图可以查看成长依据、愿望与主人回应，再启动并控制实际试做。活动结果、准备步骤、困难与取消保留区别，不把“准备好了”描述成“已经做过”。
- **纯预览与正式阶段：** 达标后查看有限造型及生活变化，明确采用时核验预览指纹。荷叶青蛙形态可与工坊学徒或灶边厨师职业组合；当前阶段卡支持分别回退形态或职业，实际经历、关系、材料消耗和另一轴保留。
- **生活记录管理：** 确认、更正或删除共享记忆，查看承诺、日报与关系趋势；作者工具保留世界线、有限计划与 NPC 目标。操作后的结果从服务端存档回读。
- **研究视图：** 事件、证据、变更账本、情境路由、来源状态和有限场景实验可回查。隔离场景与样本不改写当前正式世界；作者操作会写入正式存档，按面板说明使用。

角色阶段来自保存的愿望与当前方式跨两个上海日的实际主要结果，再加主人明确采用。当前造型是有限作者制作方案；它改变虚拟形象、生活选项和表达，不等于现实换壳、获得技能或职业资格。规则化自主安排与 DeepSeek 的有限闲时选择共用服务端任务执行边界。

## 声音、设备与验证边界

声音面板展示服务的配置与表达计划。ASR/TTS 和设备 outbox 已有软件协议；真实中文声音、人工试听与小智固件适配尚待完成。语音未配置、服务不可达、旧快照和来源过期应按实际状态显示。

页面不负责固件烧录，也不能赋予实体移动、摄像头或新的转动自由度。虚拟角色阶段与现实单轴身体、外壳感知分开记录。

第六阶段的回归、样本和截图验收限制见 [交付记录](../../research/milestones/role-development-stage6.md)。当前浏览器截图验收尚未完成，自动测试不能代替真实画面和长期生活感检查。完整现版本能力与后续步骤见 [仓库介绍](../../README.md) 和 [v0.5 路线](../../research/development-roadmap-v0.5.md)。
