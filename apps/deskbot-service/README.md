# DeskBot Service · v0.5 第六阶段

DeskBot 的本地持续世界与角色服务。它把现实输入、桌边互动、世界任务、共同经历和角色选择接到同一份 SQLite 存档，让喵呜在伴生世界“聚形域”中持续生活。3D 客户端与研究 Web 页读取服务结果，世界规则与执行记录由本服务保存。

当前产品进度为 **v0.5 第六阶段：实际试做后的可逆角色阶段**。`package.json` 的 `0.1.0` 是内部服务包版本；事件、设备和读模型各自保留协议版本，不表示产品仍停留在早期基线。

## 当前能力

- **持续生活：** 现实 1:1 时间、上海日历、持续旅行与活动任务、可变通路、苗圃与水岸状态、有限库存、配方、设施和共用物资；十二位居民与喵呜在同一个规则世界中安排活动。停机后的恢复按存档规则结算，不编造用户参与。
- **自主安排与关系：** 基本需要、路线和资源决定哪些活动可行；闲时可由配置的 DeepSeek 在有限候选中选择。共餐、交换、协作、持续项目与生活记忆留下可回查的结果，后续选择可以读取这些经历。
- **多源折射：** 时钟、天气、NASA Science 新闻、区域空气资料、用户互动、身体感知及受控 agent 输入按来源、时效和作用权限处理。外部观测影响有限处境与选项；模型台词不能直接改世界事实。
- **有依据的愿望与试做：** 实际共同结果进入成长证据和兴趣侧面，再形成已设计方向的愿望。主人可支持、稍后或拒绝；实际试做使用原旅行、活动配方与结算，不用聊天次数替代做过的事情。
- **可逆角色阶段：** 当前支持荷叶青蛙形态、工坊学徒和灶边厨师职业。形态与职业可组合，并影响虚拟 3D 造型、日常活动选项和表达。预览与正式采用分开；回退恢复对应方向，保留另一方向和已经发生的生活后果。
- **对话与输出：** 统一输入、来源上下文、表达意图、事件幂等、设备 outbox/ACK、音频工件与 WebSocket 桥。默认直接启动可使用 Fake LLM；显式配置后调用 DeepSeek 或兼容端点。

规则设计限定自主空间。当前不是开放式无限任务生成，也不是自动生成任意形象；采用方向不证明喜欢、作品质量、技能或职业资格。虚拟形态没有改变现实外壳或硬件能力。真实中文 ASR/TTS 与小智固件适配是后续阶段。

## 本地运行

需要 Node.js 24 或更高版本。先按 [配置说明](../../config/README.md) 在本机准备 `config/llm_config.json`，密钥只填本地文件。3D 客户端首次使用需在 `apps/jev-town-client` 安装依赖。

从仓库根目录启动三个入口：

```powershell
.\scripts\start-local.ps1 -StartWeb -StartWorld
```

启动脚本读取本地 LLM 配置，并优先使用已保存的 `config/weather.local.env`；也可用 `-LlmConfigPath` 和 `-WeatherEnvFile` 显式指定文件。脚本默认启用公开新闻和区域空气来源，天气是否可用取决于本地配置及实际连接状态。它检查端口与本次启动的进程，不把占用端口的旧服务当成新服务。

| 入口 | 默认地址 |
|---|---|
| 健康与 API | <http://127.0.0.1:4311/health> |
| 聚形域 3D 世界 | <http://127.0.0.1:5173/?mode=deskbot&deskbotUrl=http://127.0.0.1:4311> |
| 文字体验与研究台 | <http://127.0.0.1:4322/> |
| 第六阶段隔离样本 | <http://127.0.0.1:5173/development-review.html?sample=stages> |

停止使用 `scripts/stop-local.ps1`。只运行服务时，可在本目录执行 `npm start`；直接启动的 provider、新闻和空气开关由环境变量决定，与组合启动脚本的配置流程不同。

正式入口默认把世界、任务、输入、成长、提案、阶段和输出记录保存到 `data/deskbot.sqlite`。`DESKBOT_DB_PATH` 可指定独立数据库；研究运行使用独立数据库与明确的时间模式，普通快进回放用模拟模式，实际角色阶段实验由隔离脚本提供可控实时时钟，不能快进正式现实时间存档。同一事件编号跨重启仍保持幂等，已完成聊天不会因重试再次调用模型。

完整变量说明见 [配置与密钥](../../documentation/variables.md)。服务默认绑定 `127.0.0.1`，当前 HTTP 接口没有完整用户认证；网络发布边界见 [权限说明](../../documentation/permissions.md)。

## 世界、自主生活与模型的分工

服务先按基本需要、经历、关系、路线、库存和设施生成有限活动候选。紧急需要优先由规则处理；闲时 DeepSeek 可从现有候选中选择一项并说明理由。服务再检查候选是否仍有效，并通过原任务引擎执行每个步骤。超时、不可用或非法回答会回退到当前可行的规则安排。

模型的想法与实际结果分开保存：想做不等于做过，取消不等于完成，解释文字不能成为新的独立成长证据。用户请求可成为影响，不能绕过活动耗时、资源或设备能力。NPC 当面台词同样不直接授予世界写权限。

主要读取接口：

| 接口 | 内容 |
|---|---|
| `GET /api/world`、`/api/world/map`、`/api/world/tasks` | 唯一世界状态、地图及实际任务 |
| `GET /api/life/world`、`/api/life/autonomy` | 当前生活切片、自主安排与最近执行结果 |
| `GET /api/life/memory`、`/api/life/development` | 生活结果、成长证据与兴趣侧面 |
| `GET /api/roles/evolution`、`/api/roles/proposals` | 有依据愿望、实际试做与当前双轴角色阶段 |
| `GET /api/context`、`/api/input-runtime` | 数据来源、连接状态、缓存与调度结果 |
| `GET /api/world/ledger`、`/api/events`、`/api/evidence` | 变更、输入与证据审计记录 |

`POST /api/chat` 处理文字回合；`POST /api/life/npc-interactions` 处理当面居民互动。明确确认的记忆、承诺、计划和报告使用 `/api/life/memories`、`/api/life/commitments`、`/api/life/plans` 和 `/api/life/daily-summary`。这些记录与普通模型回复分开，编辑或取消保留各自的可解释边界。

## 愿望 → 实际试做 → 采用阶段

当前主线从 `origin: lived_wish` 的保存愿望开始，而非早期聊天反馈窗口：

1. 读取愿望并选择 `try`，形成准备意向。
2. 启动实际试做，允许暂停、恢复、调整已有方式或退出；主要活动与准备步骤分别记账。
3. 当前方式在当前回顾窗口内，跨 **两个上海日** 实际完成至少两项不同的主要任务结果，才具备采用条件。困难回顾、准备旅行、取消和旧方式的累计结果不能代替这一条件。
4. 纯预览读取原愿望、试做准入与结果，展示有限造型和生活变化，不写入世界。确认采用必须提交此预览的指纹；依据或两个当前轴版本已变化时，需重新预览。
5. 正式阶段保存在 `world.role_stages`。形态和职业分别保存当前版本与历史，虚拟造型保留种子眼、梨形体、胸口光核、短足与光粒。
6. 只能回退对应轴的当前阶段，恢复其前一版本或基础造型。另一轴、记忆、关系、资源消耗和现有实际任务保留；已用试做封存，回退后不能用同一批旧结果再次采用。

| 操作 | API |
|---|---|
| 支持、稍后、拒绝 | `POST /api/roles/proposals/:id/choose`，`choice: try\|later\|reject` |
| 实际试做控制 | `POST /api/roles/proposals/:id/practical-trial/start\|pause\|resume\|adjust\|exit` |
| 纯预览 | `GET /api/roles/proposals/:id/stage/preview` |
| 明确采用 | `POST /api/roles/proposals/:id/stage/accept`，提交 `preview_fingerprint` |
| 分轴回退 | `POST /api/roles/proposals/:id/stage/rollback`，提交当前 `stage_id` |

采用和回退可带 `event_id` 与说明 `reason`，重复事件保持幂等。公开请求不能提交任意外观、技能、任务时长或成功结果。早期 `/trial/*` 聊天反馈接口保留兼容用途，不能充当这条主线的实际试做与造型采用依据。

## 外部输入、声音与实体边界

天气支持 Open-Meteo 或配置的 QWeather。当前观测与短临、小时、每日预报分开缓存；明确最新请求才强制刷新，过期或失败不会伪装成新观测。NASA Science RSS 保留原始来源；Open-Meteo/CAMS 空气资料是区域模型资料，不是桌边传感器实测。新闻与空气状态可在输入运行层回读，未配置或失效必须按实际状态显示。

`DESKBOT_VOICE_SIDECAR_URL` 可接入 ASR/TTS；仓库 sidecar 当前提供协议用的 fake/model-free 基线。最终 ASR 才形成用户回合，TTS 工件带格式与哈希，设备消费后回传 ACK。`src/fake-device.mjs` 只作服务端联调，不能证明实体播放或动作成功。

设备桥按已登记能力处理头部触摸、屏幕触控、换壳感知与声音方向等输入，并为单轴转头保留命令与回执边界。当前实机仍是尚未适配的小智固件；没有摄像头、移动身体或新的自由度，虚拟青蛙与职业配件不会改变这些事实。
